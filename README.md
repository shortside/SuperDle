# 🛒 SuperDle

A Dutch supermarket price guessing game inspired by [Wordle](https://www.nytimes.com/games/wordle) and [Costcodle](https://costcodle.com).

## 🎮 How to Play

1. Look at the product from Dutch supermarkets
2. Guess the price in euros
3. Use the arrow hints to adjust your guess
4. Get within 5% of the actual price to win!

**You have 6 tries!**

## 🎯 Hint Colors

| Color | Meaning |
|-------|---------|
| 🟥 Red Arrow | Way off! More than 25% away |
| 🟨 Yellow Arrow | Getting warmer! Within 25% |
| 🟩 Green Check | Perfect! Within 5% - You win! |

## 🇳🇱 Features

- **6,200+ real products** from Albert Heijn
- **Real prices** from Dutch supermarkets
- **Beautiful UI** with Dutch flag colors
- **Statistics tracking** to see your progress
- **Share results** like Wordle!
